# gd.html | [Play](https://kn0tzer.work.gd/gd) | [Download](https://github.com/Kn0tzer/gd.html/releases/download/1.0/gd.html)

A complete port of Geometry Dash to a web browser

Single file only, source not included

Credit to [bog](https://jew.bio/) for getting the base port working

Changes made from the gn-math version:
- No config in-game internet support (kn0tzer.work.gd/wss)
- Fixed account syncing
- No massive lag spike every 10 seconds
- General performance improvements
- Decreased game file size
- Pressing the close game button now closes the game
- Native loading screen
- Fixed display stretching by locking aspect ratio to 16:9
